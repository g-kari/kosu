# Kosu フェーズ7：モダンWeb準拠とデザイン6ルール（v0.8.0）

フェーズ6で作った Web UI を、モダンな Web のガイドラインと Hyo と同じ
デザイン6ルール（カード禁止／パステルカラー禁止／ポエム調禁止／絵文字禁止／
アニメーション追加／図解中心）に合わせて改修した。

## モダンWeb準拠

- **CSP（Content-Security-Policy）**: 全 HTML 応答にセキュリティヘッダー付きで
  配信する。アプリが出すインライン `<script>` / `<style>` はすべて属性なしが
  構造上の前提（共通シェル＋印刷ビューのみ）なので、index.ts のミドルウェアが
  リクエストごとの nonce を刻印し、`script-src 'nonce-…'` /
  `style-src-elem 'nonce-…'` で固定する。イベントハンドラ属性は全画面で
  使っていない（すべて JS のプロパティ代入）ため script-src に
  'unsafe-inline' は不要。style 属性（動的な幅など）は style-src-attr で許可し、
  style 要素側だけを nonce で厳格化した。あわせて X-Content-Type-Options、
  Referrer-Policy、X-Frame-Options も同ミドルウェアで付ける（JSON 応答には付けない）
- **prefers-reduced-motion**: 共通スタイルシートに reduce ルールを追加し、
  アニメーション・遷移を実質無効化する（下記のアニメーション追加と対）
- **セマンティクス**: 全ページに `<footer>` ランドマーク（site-footer）を追加。
  アプリのトップバーは `<header>` 化、現在地のナビに `aria-current="page"`、
  表の見出しセルに `scope="col"`（合計行は `scope="row"`）を付与。
  印刷ビューには viewport メタが無かったので追加した

## デザイン6ルール

- **カード禁止**: `.card`（統計表示・作成フォーム）と `.detail`（タスク詳細）、
  `.topbar` の箱型ボーダーを廃止し、上端の濃い青の罫／下端の罫による
  フラットな区切りに変えた。パレットの角丸も廃止
- **パステルカラー禁止**: 薄色背景（#eef、#eef1f8、#eef4ff、#f4f6fd 等）を
  白＋枠線＋濃い青（#2456c8）に置換。タイマーチップとチップは白地＋青枠に。
  競合画面の差分ハイライトは薄色背景をやめ、濃色の内側枠に変更。
  ガントの完了色 #8a8 は #3d9970 に濃くした
- **ポエム調禁止**: タグライン「工数とタスクを静かに管理する」を
  「工数とタスクを記録・集計する」に変更。本文コピーは元から事実記述中心で、
  他に該当なしを確認した
- **絵文字禁止**: タイマーチップの ⏱、暗号文表示の 🔒、長時間警告の ⚠ を除去。
  タイマーチップには CSS の赤いドット（.timer-dot、点滅アニメーション）を
  代わりに付けた。矢印（←・↳）は記号であり絵文字ではないため残置
- **アニメーション追加**: 画面表示時のフェード（main）、ボタンとナビの
  色遷移、コマンドパレットのフェード、ダッシュボードのバー伸長、
  タイマードットの点滅。すべて prefers-reduced-motion で止まる
- **図解中心**: ダッシュボードにプロジェクト別・今週の工数の SVG 棒グラフを
  追加（表と併記）。ランディングには「記録する → 暗号化して同期 →
  集計する」の流れ図（SVG）を追加した

## ついでに直したもの（上流の CI 障害）

- リモート main は依存更新（vitest 5 化）の際にロックファイルへ vite が
  入らず、2026-11-14 12:03 UTC から CI が起動時点で落ち続けていた。
  vitest 5 は vite を peer として要求し、`npm ci --legacy-peer-deps` では
  入らないため、vite ^7 を devDependency に明示追加して解消した。
  あわせてローカル作業コピーをリモート main の依存更新（setup-node v7 /
  node 26、vitest ^5）に揃えた
