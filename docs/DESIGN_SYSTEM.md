# Kosu デザインシステム

画面の見た目と部品の仕様。実装の正は本番のスタイルガイド画面
（https://kosu.0g0.xyz/design-system 、実物のCSSで描画される）。
このドキュメントは「なぜそうなっているか」と数値の根拠を持つ。

## 原則（6ルール、2026-11-13 ユーザー指定・Kosuにも適用）

1. カードにしない：区切りは上端の濃い青の罫（3px、--brand）
2. パステルカラーを使わない
3. ポエム調の文言を使わない（事実だけを書く）
4. 絵文字を使わない（状態は色・形・文字で表す。タイマーの動作中はCSSの赤ドット）
5. アニメーションを付ける（読み込みバー、画面遷移。prefers-reduced-motion で停止）
6. 図解を中心にする（ランディングの流れ図など）

### 余白・角丸・文字

- 余白: --space-1 .25rem / 2 .5rem / 3 .75rem / 4 1rem / 6 1.5rem / 8 2rem
- 角丸: チップ・タグ 4px（--radius-chip）、ボタン・入力・パレット項目 6px（--radius-control）、区切りパネルは 0（罫のみ）
- 文字: system-ui。本文16px相当、見出し1 1.4rem、見出し2 1.1rem、補足 .85rem。数値は tabular-nums

## アクセシビリティ（数値監査の結果、2026-11-15）

- テキスト19組のコントラストは両テーマとも WCAG AA（4.5:1）全通過
- 図形の 3:1 基準は v0.8.1 で全通過（ガント未着手 #7a7a8c、菱形 #b97a1e、フォーカス #c96a00 に調整）
- タップ領域：モバイルのボタン44px・入力40px（フェーズ10）。表内リンク約29px
- フォーカスは :focus-visible に 3px の --focus 枠＋2px オフセット
- スキップリンク、ランドマーク（header/nav/main）、aria-label を維持する

## ロゴ

採用ロゴは候補A「Clock-K」（2026-11-26 決定、KAZAMI-344）。
ブランドブルー（#2456c8 系）の角丸四角に、時計の針で描いた白い「K」。
縦棒が K の背、細い矢印針と太い針が K の腕と脚を兼ねる。
配信形式は PNG で、favicon・PWA アイコン・サイドバーのブランド表示で共用する。

- /icons/icon-32.png（favicon 小）
- /icons/icon-192.png（favicon・PWA・サイドバー・SW のシェルキャッシュ）
- /icons/icon-512.png（PWA）
- /icons/icon-maskable-512.png（PWA maskable、地の青にグリフを80%で配置）
- /icons/apple-touch-icon.png（180px、地の青で全面）

実体は src/logo-icons.ts に base64 で埋め込み、src/routes/public5.ts が配信する
（Worker はコードから全資産を配信する構成のため）。差し替えるときは
原画から PNG を再生成し、manifest と shell の参照、SW のキャッシュ版数を
あわせて更新する。

## 運用

- 新しい色・余白・部品が要るときは、まずこのドキュメントとトークンに追加し、
  画面に直値を書かない
- スタイルガイド画面（/design-system）は実物のCSSで描かれるため、
  トークンを変えると見本も変わる。変えたら両テーマで目視する
