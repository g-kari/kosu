# Kosu フェーズ6：Web UI（v0.7.0）

フェーズ1〜5で API・MCP・同期・連携を先に作ったため、画面は最小構成だった。
フェーズ6ではブラウザで日常業務が完結する Web UI を追加した。

## ルート構成

| ルート | 内容 | 認証 |
| --- | --- | --- |
| `GET /` | HTML ランディング（概要、ログイン導線、/terms・/privacy リンク、ツール向け案内）。Accept: application/json のみの場合は従来の識別 JSON を返す | 不要 |
| `GET /health` / `GET /api/health` | 識別 JSON `{name, service, status, version}` | 不要 |
| `GET /app` | ダッシュボード | 必須（未認証は 302） |
| `GET /app/tasks` | タスク一覧・詳細 | 必須 |
| `GET /app/time` | 工数（タイマー・手入力・週表示） | 必須 |
| `GET /app/gantt` | ガント（シェル内 SVG） | 必須 |
| `GET /app/reports` | レポート | 必須 |
| `GET /app/settings` | 設定ハブ（プロフィール・API キー・利用量・鍵） | 必須 |

既存の /app/projects/:projectId/gantt（単体 SVG）、/app/conflicts、
/app/settings/integrations、/app/preferences、/app/onboarding はそのまま残し、
新シェルから導線を張っている。

## 共通シェル（src/routes/ui.ts）

- サイドバー：ダッシュボード／タスク／工数／ガント／レポート／設定＋設定系リンク
- トップバー：テナント／ワークスペース／プロジェクト切替（選択は localStorage の
  `kosu_ctx` に保持）、実行中タイマーのチップ（60 秒ポーリング＋1 秒ティック、
  その場で停止可）、アカウント名、ログアウト
- フェーズ5の仕組みと連携：コマンドパレット（Cmd/Ctrl+K）、テーマとロケールは
  user_prefs をそのまま使う。新規画面の見出しは i18n 辞書に追加済み

## 各画面

- **ダッシュボード**: 今日・今週の工数（dashboard API、今週は user_prefs の
  週開始曜日を反映）、進行中タスク、期限が近いタスク（全プロジェクト横断、
  7 日以内・未完了・期限順）、プロジェクト別サマリ（件数と今週の工数）、
  同期ステータス（端末登録と競合への導線）
- **タスク**: 検索・担当・ラベル・期限範囲・ステータス・優先度・アーカイブ表示で
  絞り込み、行内ステータス変更、作成。詳細パネルで編集・削除・見積もり・
  サブタスク（追加・遷移）・依存（前提の追加/解除、被依存の表示）・ラベル付け外し・
  タスク単位の工数サマリとタイマー・コメント（投稿・表示）
- **工数**: プロジェクト→タスクを選んでタイマー開始（タスクなしも可）、
  手入力の追加・編集・削除、週ナビゲーション、日別グループ表示と日・週合計、
  長時間記録の警告表示
- **ガント**: 既存のガント API から SVG をシェル内に描画（依存の矢印、
  マイルストーン、今日線、見積もり表示）。プロジェクトはトップバーで切替
- **レポート**: 期間プリセット（今週・先週・今月・先月）と任意期間、
  集計単位（プロジェクト／メンバー／タスク／日別）、プロジェクト・自分のみの
  絞り込み、合計行、CSV ダウンロード・JSON・印刷/PDF 向け表示へのリンク。
  プロジェクト ID とメンバー ID は画面側で名前に解決する
- **設定**: プロフィール（/api/v1/me）、API キーの一覧・発行（平文は1回だけ
  表示、スコープと許可 IP 指定可）・失効、利用量と上限、暗号化キーパネル、
  連携設定・表示設定・初期設定・競合・法務ページへの導線

## 暗号化（ブラウザ側）

タスクの説明とコメントは暗号文のまま API を往復する。ブラウザ側は
client/vault.js と同一のワイヤ形式（`v1.` 接頭辞、AES-GCM、復旧コード＋
PBKDF2-HMAC-SHA256 でラップされた ADK）を再実装し、復旧コードで
アンラップした ADK を sessionStorage にのみ保持する。ロック中は暗号文を
「🔒」表示にし、編集・投稿を無効化する。サーバーに平文は送らない。

## 追加した読み取り API

- `GET /api/v1/me`: アカウント情報＋所属テナント一覧＋
  `account.default_tenant_id`（個人用テナント優先）。フェーズ2〜5の画面 JS が
  参照していたが未実装だったため、今回あわせて実装した
- `GET /api/v1/tenants/:tenantId/members`: メンバー一覧
  （account_id / display_name / email / role）。担当者選択とレポートの
  名前解決に使う。非メンバーには 404

## 互換性

- `/` の JSON を期待する利用向け: Accept: application/json のときは従来どおり
  JSON を返す。正規のヘルスチェック先は /health と /api/health
- API の JSON 応答、MCP、同期プロトコルは変更していない

## 到達範囲（今回含めていないもの）

- 階層の新規作成 UI（テナント／ワークスペース／チーム／プロジェクト）
- タスクの添付、カスタムフィールド、保存フィルター、一括編集、変更履歴の UI
- 自動化ルール、プロジェクトテンプレート、カスタムレポート定義の管理 UI
- いずれも API・MCP では利用可能。今後の画面拡張で扱う
