# フェーズ10：UI/UX 改善（v0.11.0）

数値監査の残件と、実画面の摩擦をもとに実施。

## タッチとマウス
- モバイル（860px以下）：ボタン最小44px、入力・選択は40px、サイドバーのナビは padding 拡大、タイマーチップの停止ボタン36px
- 表内のリンク（「開く」等）：全画面で inline-block＋padding により当たり判定を約19px→約29pxへ（数値監査の残件解消）

## フィードバック
- 読み込みバー：共有 api() の実行中は画面上部に細いバーを表示（busybar）。通信中かどうかが常に見える
- トースト：タスク作成、タイマー開始／停止、工数の追加／修正で完了通知を右下に3.2秒表示

## 操作性
- タスク一覧の行がキーボード操作可能に（Tab でフォーカス、Enter／Space で選択。行内の select 等は対象外）
- 空状態：タスクが0件のとき「最初のタスクを作成」ボタンで作成フォームへ誘導。絞り込みで0件のときは文言を分けた
- コマンドパレットの入力に aria-label を追加（数値監査の残件解消）
